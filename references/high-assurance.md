# High Assurance

Use Standard for security-sensitive, destructive, production-critical, schema,
auth/RBAC, browser, external-state, or explicitly strict work.

High assurance adds independent review of the integrated tree and evidence:

- P5 applies only accepted worker outputs.
- P6 reviews state ownership, integration diff, and release blockers.
- P7 checks functional workflows when applicable.
- P8 checks visual/UI artifacts when applicable.
- P9 checks persona and interaction behavior when applicable.

Blocking findings return to the owning lane with exact evidence and required
reruns. Do not reuse stale receipts across contract, generation, input identity,
or output artifact changes.
